# 🌍 Dawa Tran - Portfolio V4

A modern, interactive portfolio showcasing my work as a GIS Specialist and Geographer, built with cutting-edge web technologies and stunning 3D visualizations.

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://emepuert.github.io/AtlasV4/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## ✨ Features

### 🏠 **Interactive Home Page**
- **Custom Preloader** with animated globe and progress bar
- **3D Globe Visualization** powered by Globe.gl and Three.js
- **Scroll-based Navigation** with smooth transitions between sections
- **Circular Navigation Buttons** with glassmorphism effects
- **Star Field Background** with randomized twinkling animations

### 🎯 **Skills Showcase (Page 1)**
- **4 Interactive Sections**: IT Skills, Urban Planning, GIS, Data Analysis
- **Dynamic Globe Transitions** with texture changes and smooth rotations
- **Skill Cards** with animated progress bars
- **Glitch Text Effect** on all section titles
- **Color-Coded Sections**: Cyan, Gold, and Red themes
- **Navigation Dots** for easy section switching

### 👤 **About Me (Page 2)**
- **Modern Glassmorphism Design**
- **Glitch Photo Effect** - profile picture with creepy Easter egg
- **Professional Experience** timeline with hover effects
- **Education Section** with academic background
- **Animated Globe Footer** with floating clouds
- **Color-Coded Titles** for visual hierarchy

### 🖼️ **Work Gallery (Page 3)**
- **Premium Gold Card** for flagship project (Huntsterpieces)
- **Interactive Lightbox** with multi-image carousel
- **Download Buttons** for R code projects
- **Project Categories**: Web Development, GIS Analysis, Data Visualization
- **External Links** to live projects
- **Responsive Grid Layout**

## 🗺️ Featured Projects

### 🏆 [Huntsterpieces](https://hunsterpieceslanding.netlify.app/) - GPS Treasure Hunt Platform
Full-stack SaaS application for creating interactive GPS treasure hunts with real-time tracking, Firebase backend, and admin dashboard.
- **Technologies**: Firebase, Leaflet.js, JavaScript, GPS Geolocation
- **Features**: Real-time sync, 50m detection radius, team management

### 🐾 Bigfoot Sightings Interactive Map
Animated timeline visualization of Bigfoot sightings across the United States with temporal analysis.
- **Technologies**: Leaflet.js, GeoJSON, Stamen Terrain
- **Features**: Dynamic timeline, classification filters, animated footprints

### 🏠 French Lighthouses Cartography
Artistic cartographic visualization of lighthouses along the French coastline.
- **Technologies**: R, ggplot2, spatial libraries
- **Download**: R source code available

### 🏔️ Gérardmer 3D Terrain Model
LiDAR-based 3D reconstruction using photogrammetry and rayshader.
- **Technologies**: R, rayshader, LiDAR data
- **Download**: R source code available

### 🌊 London Thames Flood Risk Assessment
Comprehensive flood depth analysis with 3 scenarios (5m, 10m, 15m).
- **Technologies**: QGIS, GIS Analysis, Hydrological Modeling

## 🎨 Design Principles

- **Glassmorphism**: Blur effects and transparency
- **Color Palette**: 
  - Primary: Cyan (#8fd3f4)
  - Secondary: Gold (#FFD700)
  - Accent: Red (#ff6b6b)
  - Background: Gradient from black to cyan
- **Typography**: Space Mono monospace font
- **Animations**: Smooth cubic-bezier transitions
- **Visual Effects**: Glitch text, floating elements, pulsing glows

## 🎯 Special Effects

### Glitch Text Animation
All major titles feature a custom glitch effect that randomly scrambles letters periodically, creating a cyberpunk aesthetic.

### Globe Transitions
When navigating between skill sections, the globe rapidly spins, blurs, changes texture mid-rotation, then smoothly returns to normal speed.

### Photo Glitch Easter Egg
The profile picture on page 2 occasionally (every 10-30 seconds) flashes to a "creepy" version for 600ms with a shake effect.

### Premium Card Design
The Huntsterpieces project features a unique gold-themed card with animated border shimmer and special hover effects.
